# Guía para Contribuir al Proyecto Udeney

¡Gracias por considerar contribuir a Udeney! Queremos mantener un ambiente saludable, colaborativo y productivo para todos los desarrolladores.

## 🌱 Requisitos Previos

Antes de comenzar, asegúrate de tener instalados:

- Python 3.10+
- Node.js 18+
- MySQL
- Docker (opcional)

También es importante leer el archivo `README.md` para conocer la arquitectura y cómo levantar el entorno local.

---

## 🚀 Proceso de Contribución

1. **Fork** del repositorio.
2. Clona tu fork:

   ````bash
   git clone https://github.com/tu-usuario/Udeney-v1.git
   ```
   ````

Crea una nueva rama:

bash
Copiar
Editar
git checkout -b mi-mejora
Realiza tus cambios. Usa:

black y flake8 para backend

eslint, prettier para frontend

Haz commit de los cambios:

bash
Copiar
Editar
git commit -m "Descripción breve del cambio"
Haz push a tu fork:

bash
Copiar
Editar
git push origin mi-mejora
Abre un pull request a la rama develop.

🧼 Convenciones de Código
Sigue las reglas de linting (flake8, black, eslint, prettier)

Usa nombres claros para variables, funciones y commits

Evita console.log y print en producción

Añade comentarios solo donde sea necesario

Gracias por apoyar este proyecto educativo
